Pengaturan Firebase

Masukkan konfigurasi Firebase milik Anda di dalam kode HTML pada bagian FIREBASE CONFIG. Data disimpan di Realtime Database.

Database URL dan project ID harus berasal dari project Firebase yang sama. Aktifkan Realtime Database dan atur aturan keamanan sebelum digunakan.

Cadangan & Keamanan

Gunakan akun Firebase pribadi. Jangan membagikan file konfigurasi admin atau private key. Firebase web config bukan password, tetapi akses database wajib dilindungi dengan Firebase Authentication dan Security Rules.
